# 练迹 v2.7.0 · 计划复用

- 在计划页把常用计划标记为收藏。手机首页、手机计划页和 Apple 原生端优先展示收藏项，手机计划页还可只看「常用」。
- 从已有计划选择「复制计划」。手机端先打开可编辑草稿，Mac 和 Apple Watch 确认后创建副本。同名副本自动编号。
- 副本沿用动作顺序、组数、重量、次数或秒数、休息和说明，使用独立的计划身份。
- 手机、Mac 和 Apple Watch 导出的备份包含收藏设置，恢复不含收藏字段的旧备份时，收藏列表为空。

四端版本为 2.7.0，构建号为 15。

## 验证与发布状态

- 已通过 lint、类型检查、SQLite 与 Swift 回归测试、iOS 和 Android 代码与资源打包，以及 Mac（Apple Silicon）和 Apple Watch 模拟器构建。
- 回归测试覆盖收藏的跨端备份恢复与失败回滚、旧数据升级、独立副本的动作和单位保留，以及副本编辑和关联数据的独立性。
- 本次为源码更新，签名安装包和真机交互验收待完成。
