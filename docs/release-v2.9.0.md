# 练迹 v2.9.0 · 更换待练动作

- 在进行中的训练里，尚无完成组的动作可选择「更换动作」。从动作库选好后，确认原动作、新动作、组数和默认目标，再完成更换。已有完成组的动作保留原记录。
- 更换会沿用组数、顺序、组号与每组休息时间。新动作的重量预填为 0 kg，按次动作预填 10 次，按秒动作预填 30 秒，可继续调整。自定义动作默认按次记录。
- 本次训练已有的动作不会再次出现在可选列表。更换只影响本次训练，原计划与历史记录保持原样；上次组次对照会按新动作重新匹配。
- 手机计划编辑也支持「更换动作」，沿用草稿的组数和休息，并重新预填新动作的重量与目标，保存后生效。
- 更换操作失败时保留原数据，旧输入事件无法覆盖新动作。更换期间暂停该动作的编辑与训练保存，成功后清除原动作的计时，其他动作的计时继续。

四端版本为 2.9.0，构建号为 17。现有数据和备份格式保持兼容。
