# 练迹 v1.0.2 预览版

## 新增内容

- 训练计划由 4 套扩充到 12 套，共 34 个训练日。新增新手全身 A/B、上下肢 2分化、上下肢 4日、推拉腿 6日、居家哑铃、居家徒手、基础力量 5×5、30分钟全身。
- iOS / Android、macOS 和 Apple Watch 共用计划目录，支持按场景筛选，并显示适用水平、器材、建议频率、热身与渐进说明。
- 新增 6 个内置动作及动图映射，动作库共 36 个动作。在线动图需网络，素材来源见动作素材说明。
- 旧版本首次打开会补齐新增内置动作，保留已有计划、训练记录和自定义动作；模板重复添加不覆盖原有编辑。

## 安装

[下载 Android APK](https://github.com/allen7wang/lianji/releases/download/v1.0.2/Lianji-1.0.2-Android.apk)。Android 7.0+，安装后可独立运行。应用标识保持 `com.allenwang.lianji`，版本号 1.0.2、版本代码 3，使用与 v1.0.1 相同的发布签名，可直接覆盖升级；不要卸载旧应用以免删除数据。

[发布页](https://github.com/allen7wang/lianji/releases/tag/v1.0.2)提供 Mac 通用预览包和 Apple Watch 模拟器包。Mac 包尚未签名或公证；手表包仅供模拟器使用，不能安装到真实 Apple Watch。iPhone 新计划已包含在源码中，使用 `npm run preview:ios` 更新模拟器；旧 v1.0.1 模拟器二进制不包含这些新计划。

## 内容说明

模板是可编辑的通用起点，不是自动排课功能；推荐频率只作为文字说明，用户自行安排训练和休息。平板支撑的次数按秒记录，单侧动作次数按每侧计算。计时器默认 90 秒，力量组可等待充分恢复后再继续。

居家徒手计划不包含负重拉类动作。居家哑铃计划不需要训练凳，单臂划船可用另一只手扶大腿支撑。30分钟全身是时间估计，器械等待、热身和组间休息会影响实际时长。

模板依据通用训练原则独立编写；参考 [ACSM 2026 抗阻训练立场文件](https://doi.org/10.1249/MSS.0000000000003897)，不表示这些具体模板由 ACSM 指定或背书。

## 验证

代码规范、类型检查和隔离 SQLite 验证覆盖新安装、旧数据库迁移、同名自定义动作、整套导入、重复导入、已有编辑保留、补齐缺失训练日和出错回滚。GitHub Actions 检查 iOS / Android 资源打包。

Android 发布包经过固定密钥签名与包校验，最终包验证及计划界面流程结果见发布页。macOS 通用客户端和 watchOS 模拟器客户端已通过原生编译；本版未做 Apple 真机验收。各端数据仍独立保存在本地，没有云同步。
