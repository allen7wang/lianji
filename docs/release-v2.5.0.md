# 练迹 v2.5.0 · 数据备份

- Mac 侧栏和 Apple Watch 首页新增「数据备份」。Mac 可导出并恢复全部计划、训练记录、每周目标、训练安排、身体和饮食数据。手表先准备备份，再通过系统分享保存 JSON；watchOS 没有文件选择器，不能在表上恢复。
- 备份格式与 iPhone / Android 的「我的 → 数据与备份」相同。手机、Android 和 Mac 可以互相恢复，也可以恢复手表分享出来的备份。无需账号或云同步。
- 恢复前会检查版本、记录编号、计划和训练引用、每周目标与训练安排。无效文件不会改动现有数据；写入失败时保留恢复前的内容。
- 缺少每周目标的旧备份会沿用本机目标。没有训练安排的旧备份会清空安排，避免安排指向已被替换的计划。

四端版本为 2.5.0，构建号为 13。升级后可直接用已有记录导出备份。

## 验证与发布状态

- 已通过 lint、类型检查、SQLite 与 Swift 回归测试。回归覆盖手机格式导入、旧备份兼容、重复与无效数据拒绝，以及写入失败时不替换现有数据。
- 2.5.0 目前为本地源码版本。签名安装包和真机交互验收待完成。
