# 练迹 v2.0.0 · 训练进度

## iOS 和 Android

- 「进度」里的训练日历支持周、月和全部记录。选中一天可查看当日汇总与训练明细，容量图可直接打开对应的训练记录。
- 动作进步可按动作名、器械或部位搜索，查看单组最大重量、单组最多次数、单组最长时长和单次训练容量。最近六次有相应数据的训练可逐条查看。
- 训练保存后直接打开回顾页，显示完成组数、动作明细、首次成绩与个人新高。历史详情可选择「再练一次」，复制已完成组的训练设置。已有进行中的训练时，会提示先处理当前训练。

## macOS 和 Apple Watch

- 从 Mac 侧栏进入「训练进度」，可切换周次并点选日期查看当天的训练记录。Apple Watch 首页的「训练进度」显示本周和上周的训练天数与完成组数。
- 动作纪录按动作区分，显示重量、次数和时长的最佳成绩及近期表现。

## 数据兼容

- 四端版本为 2.0.0，构建号为 8，沿用各端既有应用标识。
- 训练进度根据本设备已保存的训练和已勾选的组计算。训练日期按本地开始时间归属，跨午夜的训练归入开始当天。按秒组独立统计时长，按次组按重量 × 次数计入容量。
- SQLite 表结构、手机 JSON 备份版本和 Apple 原生端训练文件格式保持兼容。旧记录在升级后可直接显示在进度视图中。

## 验证与发布状态

- 已通过 lint、类型检查、SQLite 和 Swift 回归测试，以及 macOS 通用构建和 watchOS 模拟器构建。
- v2.0.0 目前为本地源码版本。签名安装包与真机交互验收待完成，公开下载仍为 v1.3.1。
