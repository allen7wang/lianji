# 练迹 v2.6.0 · 身体与饮食趋势

- iPhone、Android 和 Mac 显示最近体重相对上次的增减。至少两次记录时可查看体重趋势；有体脂记录时也可查看体脂率趋势。
- 饮食记录按本地日期汇总近期有摄入的日子，显示当日热量。没有记录的日期不会补空。
- Apple Watch 首页新增「身体饮食」，以文字显示最近体重、相对上次的变化、今日热量，以及最多 8 条近期体重。手表没有文件选择器，不能在表上恢复备份。

四端版本为 2.6.0，构建号为 14。升级后可直接用已有身体和饮食记录查看变化。

## 验证与发布状态

- 已通过 lint、类型检查、SQLite 与 Swift 回归测试，以及 Mac 和 Apple Watch 模拟器编译。回归覆盖同时间记录的编号次序、体重增减、体脂独立窗口，以及同一本地日的饮食汇总。
- 2.6.0 目前为本地源码版本。签名安装包和真机交互验收待完成，公开下载仍为 v1.3.1。
