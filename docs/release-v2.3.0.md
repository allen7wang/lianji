# 练迹 v2.3.0 · 训练安排

- 手机从「今天」或「计划」打开「训练安排」。可按周浏览，选择今天或之后的日期，并加入一个或多个已有计划。「今日安排」可直接开始当天的计划。
- Mac 从侧栏进入「训练安排」。Apple Watch 从首页进入，可为今天及接下来的六天添加计划。两端均可查看、取消安排和开始当天的计划。
- 训练保存后，系统按计划与本地开始日期匹配安排。至少完成一组才会显示「已完成」。没有完成的安排按日期显示为「已安排」「待训练」或「已错过」。
- 手机备份会保存计划和关联安排。恢复没有训练安排的旧备份后，安排列表会清空，可重新为计划选日期。

四端版本为 2.3.0，构建号为 11。升级后可以直接给已有训练计划添加安排。
