# 练迹 v2.8.0 · 沿用上次组次

- 在正在训练的未完成组选择「沿用上次」，即可填入上次对应组的重量和次数或秒数。填入后可以继续手动调整，并按实际情况完成这一组。
- 对照沿用现有的「上次组次」来源，按同一动作、同一单位的组次顺序对应。本次已完成组也占据其原来的序号，后续组继续对应原来的位置。
- 按次与按秒分开匹配。每次沿用只填写当前组的重量与目标，休息按本次训练设置。
