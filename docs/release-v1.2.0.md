# 练迹 v1.2.0 预览版 · 呼吸训练

## 新增内容

- 新增「呼吸训练」分类和六套计划：腹式呼吸入门、等长呼吸练习、延长呼气练习、方块呼吸练习、训练后呼吸整理、睡前呼吸放松。
- 合计 34 套计划、69 个训练日、55 个内置动作及演示。保留原有 HIIT、动物流和九项专项力量计划。
- 四种离线呼吸节奏：腹式与等长为 4 秒吸 / 4 秒呼；延长呼气为 4 秒吸 / 6 秒呼；方块为吸气、吸后停留、呼气、呼后停留各 4 秒。默认入门练习无屏息；方块练习单独列出。
- 呼吸引导显示阶段提示、阶段秒数、总剩余时长、已完成循环数和圆环动画；支持暂停、继续与重新开始，进入后台时暂停。阶段节奏固定，练习秒数可以修改。
- iOS、Android、Mac 和 Apple Watch 共用目录和阶段参数。原有 GIF 演示保留，新增呼吸动画不需要网络。

## 使用

手机进入「计划 → 计划模板 → 呼吸训练」，预览并添加练习，然后开始训练，点击「呼吸引导 N 秒 → 开始引导」。Mac 从训练计划进入相同分类；手表从首页的计划模板进入。

圆环展开时吸气、缩小时呼气；方块呼吸还有保持阶段。按舒适幅度轻柔呼吸，不追求最大吸气量或更长屏息。引导可暂停或重新开始。进入后台会暂停，回到应用后需手动继续。关闭引导页面后本次进度不保存，再次打开从准备开始。

引导结束后按实际完成情况勾选本组并保存训练。呼吸练习按秒记录，不计入力量容量。练习不会自动勾选完成。模板不提供疾病诊断或疗效判断。

## 升级与安装

手机标识仍为 `com.allenwang.lianji`，版本 1.2.0、版本代码 5；Android 沿用同一发布签名。覆盖安装保留原计划、编辑内容和训练记录；不要先卸载旧版本。

本版无需增加数据库字段，只追加四个内置呼吸动作；旧的自定义同名动作不自动转换。四端仍各自保存本地数据。

[Android APK](https://github.com/allen7wang/lianji/releases/download/v1.2.0/Lianji-1.2.0-Android.apk)和 Apple 预览包见[发布页](https://github.com/allen7wang/lianji/releases/tag/v1.2.0)。Mac 包未签名或公证；iPhone / Apple Watch 包仅用于模拟器，无法安装到真机。尚未发布到应用商店。

代码检查覆盖规范、类型和真实隔离 SQLite 数据升级、计划导入、训练记录保存。呼吸测试覆盖零秒停留跳过、阶段边界、完整循环、暂停期间不累计时间、继续与重新开始、同名自定义动作排除。Apple 共享数据测试覆盖相同节奏规则和旧记录保留。
