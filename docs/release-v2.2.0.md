# 练迹 v2.2.0 · 每周训练目标

- 四端支持设定每周训练 1–7 天，也可关闭目标。iOS 和 Android 在「今天」或「进度」设置，Mac 和 Apple Watch 在「训练进度」设置。
- 每周从本地周一开始，包含至少一组已勾选完成的已保存训练才计入训练日。同一天的多场训练合计一天，跨午夜的训练归入开始当天。
- 手机「进度」和 Mac「训练进度」可回看本周及过去三周的训练天数，便于对照近期训练节奏。
- 各端在本机保存设置。手机备份包含目标，恢复旧备份时可以沿用本机已有目标。

四端版本为 2.2.0，构建号为 10。升级后可直接用已有训练记录查看本周进度。

## 验证与发布状态

- 已通过 lint、类型检查、SQLite 与 Swift 回归测试、iOS 和 Android 代码与资源打包，以及 Mac（Apple Silicon）和 Apple Watch 模拟器构建。手机回归测试覆盖上海和洛杉矶时区的跨周统计。
