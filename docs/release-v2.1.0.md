# 练迹 v2.1.0 · 训练复盘

## 编辑训练记录

在 iOS 或 Android 进入「进度 → 训练记录」，打开一场已保存的训练，再点右上角的编辑图标。可以修正名称、笔记、每组重量、次数或秒数，以及组的完成状态。保存时至少保留一组有效的完成记录，训练容量、动作趋势和个人纪录会随保存结果重新计算。

## 存为训练计划

在手机训练明细、Mac 训练历史或 Apple Watch 历史中选择「存为训练计划」。手机打开可编辑的计划草稿，Mac 和 Apple Watch 确认后直接添加到计划。

每个动作取最后一个有效完成组的重量、次数或秒数和休息时间，组数按同单位的有效完成组计算。计划按组数 20、次数或秒数 1000、重量 2000 kg、休息 600 秒的上限预填。同名计划会自动编号。

## 数据兼容

四端版本为 2.1.0，构建号为 9。旧训练记录可以直接编辑或转换为计划，SQLite 和 JSON 备份格式兼容已有安装。
