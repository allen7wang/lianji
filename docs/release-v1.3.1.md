# 练迹 v1.3.1 预览版 · 完整离线动作演示

## 本轮更新

- 补齐上一版仍需联网的 25 项默认动图：新增 9 项真人素材、16 项练迹原创示意。现有 55 个内置动作全部有离线演示，包括 51 项本地 GIF（25 项真人、26 项原创示意）和 4 项程序呼吸动画，无需先联网缓存。
- 新增真人演示涵盖杠铃划船、肩推、深蹲、罗马尼亚硬拉、腿屈伸、自重深蹲、俯卧撑、悬垂举腿和壶铃摆动。逐项核对实际器械、动作变式、作者和文件许可，保留原文件来源、SHA-256 与可复现转换参数。
- 为暂未找到合适许可真人素材的动作提供原创关节与器械示意，明确标记“离线示意”“非真人”。包括夹胸、下拉、单臂划船、分腿蹲、下压、卷腹、硬拉、弓步蹲、臀桥、高脚杯深蹲、登山跑、波比、熊爬、死虫式、登阶和单腿硬拉。
- 手机与 Apple 原生端按明确的素材类型显示真人、示意或呼吸标签，不再通过提供方名称猜测；手机演示按资源宽高比适配。所有动作保留原中文教学、暂停及查看步骤入口。
- 保留可选联网模型参考，但不再用其作为默认演示，也不下载或打包授权未明确的原型媒体。默认演示离线可用；主动打开来源、许可和可选模型链接仍需要网络。

## 数据与兼容

- 原有 55 个动作 ID、名称、教学、训练计划与记录保持不变，同名自定义动作仍不会自动借用内置演示或教学。
- 本轮不修改数据库结构和备份格式，手机备份格式版本仍为 1。各端数据仍各自独立，暂无自动跨设备同步。
- 手机应用标识保持 `com.allenwang.lianji`，版本为 1.3.1、版本代码为 7；Apple 原生端同步为 1.3.1 / 7。Android 沿用既有发布签名，升级时请直接覆盖安装，不要先卸载旧版。

## 检查与边界

- 发布前运行类型、代码规范、隔离 SQLite 逻辑、素材映射与 GIF 解码检查。发布工作流从固定源码标签构建四端软件包，实际构建结果和校验信息见发布附件 `BUILDINFO.json` 与 `SHA256SUMS`。
