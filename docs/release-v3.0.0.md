# 练迹 v3.0.0

版本号为 3.0.0，构建号为 19。

## 更新

- iOS、Android、Web、macOS 和 Apple Watch 使用「迹线」设计。手机、Web 和 Mac 跟随系统明暗模式，Watch 使用深色。
- 逐组记录支持热身组和 RPE，重量可在 kg 和 lb 之间切换，已有重量仍以 kg 保存。热身组计入完成组数，训练容量和个人纪录按正式组计算。
- 动作进度支持估算 1RM。训练中可以参考上次正式组的完成情况，将重量建议应用到未完成的正式组。
- 手机端休息计时可在退出训练页后继续，支持本地通知、震动和训练页常亮。Web 提供应用内计时。
- 手机、Web 和 Mac 可合并或替换导入 JSON。导入前自动保留快照，可撤销最近一次导入。Watch 支持分享备份。
- 手机、Web 和 Mac 可设置热量、蛋白质目标并快速记录最近吃过或常吃的食物。Watch 显示目标进度并支持重记最近食物。
- 用户授权后，iOS 和 Android 可分别向 Apple 健康或 Health Connect 写入新保存的训练、体重和体脂率。Watch 可写入完成的训练。
- v3 Android 安装要求 Android 8.0 或更高版本。Health Connect 开关只在系统服务可用时出现。

## 数据升级

SQLite 和 Apple 本地存储会规范化已有内置动作的 ID，并更新训练与计划引用。v1 JSON 备份可继续导入，旧组次缺省为正式组，RPE 缺省为空。参见[数据约定](data-contract.md)。

## 发布状态

- TypeScript、SQLite 和 Swift 回归通过，覆盖旧备份导入、热身组统计、估算 1RM、合并和撤销。
- Web 已跑通单位切换、备份恢复、饮食目标和快捷记录，以及跨页休息计时和训练保存。
- Mac 通用构建、Watch 模拟器和设备 SDK 编译已通过。
- iOS、Android 和 Web 的 Expo 导出已通过。Android 16 模拟器通过了验收 APK 安装、离线启动、模板导入、训练与历史记录、饮食记录以及 v1 JSON 合并与撤销。
- Android 16 系统已收到动作计时通知。Health Connect 中已核对练迹写入的训练、体重和体脂率。
- Android 模拟器使用独立包名和本地测试签名。正式签名包的覆盖升级、真机和商店发布需单独验收。
