# 练迹 v2.10.0 · 调整动作顺序

- 在进行中的训练里，每个动作可选择「上移」或「下移」，与相邻动作交换位置。已有完成组的动作也可移动，方便按现场器械情况调整训练顺序。
- 移动以整个动作为单位，保留每组的组号、重量、次数或秒数、完成状态和休息设置。同一动作里的组次顺序与正在运行的计时保持不变。
- 训练中的排序只影响当前训练，保存后按调整后的顺序展示历史。原计划与其他历史记录保持原样。
- 手机和 Mac 计划编辑可调整草稿动作顺序，保存后生效。手机编辑中的输入跟随原动作移动，可继续修改目标。
- 首项无法上移，末项无法下移。重复操作会等待当前移动完成；如果训练或动作列表已变化，会提示重新查看。保存失败时保留原顺序。

四端版本为 2.10.0，构建号为 18。现有数据和备份格式保持兼容。
