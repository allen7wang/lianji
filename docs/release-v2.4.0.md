# 练迹 v2.4.0 · 训练对照

- 训练过程中展开动作的「上次组次」，可以看见最近一次可对照训练的日期、名称和各组成绩。按次和按秒分别查找上次记录，记录按动作区分。
- 训练保存后，可在历史查看「同计划对照」。它展示上次与本次的有效完成组数、训练容量和计时总时长。手机端可点「查看上次」打开原记录。
- 对照以本次训练的开始时间为界，从此前已经保存的训练中选取来源，组次按原来的组号呈现。有效组是已勾选完成且次数或时长大于零的组，按秒组单独计入总时长。

四端版本为 2.4.0，构建号为 12。升级后可直接使用已有记录做对照。

## 验证与发布状态
